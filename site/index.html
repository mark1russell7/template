Template

The template of the repositories of mark1russell7. It holds the shared CI, release and Pages workflows, and the packages that check the conventions of each repository.

ReleasesThe versions of each package, the newest first. StatusThe roadmap, the open pull requests and the open issues. SourceThe repository on GitHub.

Documents

CI.mdThe shared workflows and actions, and their inputs. RELEASING.mdHow a release to npm operates.

Packages

  • @mark1russell7/conventionsOne check in CI for the conventions of a repository.
  • @mark1russell7/site-pagesThe Releases page and the Status page of a site.
  • @mark1russell7/api-reportA report of the public API of a package.
  • @mark1russell7/boundariesThe import boundaries of a workspace.
  • @mark1russell7/template-cliNew repositories and packages from the template.
